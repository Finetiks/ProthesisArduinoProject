# Керування протезом

Шпаргалка для користувача. Передбачається, що протез уже
[відкалібрований](calibration.md).

---

## Керування м'язом

Один канал EMG має передавати більше, ніж «напружено / не напружено», тому
прошивка розрізняє **як саме** напружений м'яз.

| Що зробити м'язом | Що станеться |
|---|---|
| плавно напружувати й тримати | кисть стискається пропорційно силі напруження |
| розслабити | кисть розкривається |
| **два коротких** скорочення підряд (як «подвійний клік») | наступний жест |
| **напружити сильно й тримати** ~1.2 с | хват фіксується, можна розслабити м'яз (звучить довгий сигнал) |
| одне коротке скорочення, коли хват зафіксований | фіксація знімається, кисть розкривається |

Фіксація хвату — головна річ для реального користування. Щоб пронести пакет
два квартали, не потрібно тримати м'яз напруженим: зафіксували хват, м'яз
відпочиває, кисть тримає.

Коротке скорочення — це 40–400 мс. Звичайний робочий стиск триває довше, тому
жест випадково не перемкнеться.

## Керування джойстиком

### На головному екрані

| Дія | Результат |
|---|---|
| `←` `→` | попередній / наступний жест |
| клік | зафіксувати / зняти фіксацію хвату |
| довге натискання | **відкрити меню** |
| `↑` `↓` | стискати / розкривати кисть (у ручному режимі) |

Меню відкривається лише довгим натисканням — щоб не спрацьовувало випадково
в кишені або під одягом.

### У меню

| Дія | Результат |
|---|---|
| `↑` `↓` | перейти між пунктами |
| `←` `→` | змінити значення вибраного пункту |
| клік | виконати дію (калібрування, діагностика, зберегти, скинути) |
| довге натискання | вийти на головний екран |

Знак `<` біля значення означає, що цей пункт міняється стрілками вліво/вправо.
Окремого режиму редагування немає.

Меню саме закривається через 15 секунд без дій — протез не має залишитись у
ньому, якщо людину щось відволікло. Під час калібрування таймер не працює.

**Керування кистю в меню продовжує працювати.** Це протез, а не гаджет: рука
потрібна саме зараз, навіть коли на екрані налаштування.

## Жести

| Жест | Для чого | Особливість |
|---|---|---|
| **Долоня** | стан спокою, потиснути руку | пальці не рухаються взагалі — безпечний стан за замовчуванням |
| **Кулак** | силовий хват усією кистю | |
| **Циліндр** | бутилка, склянка, поручень у транспорті | великий палець обгортає збоку, не доводиться до кінця |
| **Щипок** | дрібні предмети двома пальцями | решта пальців підігнута, щоб не чіплялись |
| **Тринога** | ручка, ключ від квартири | стабільніший за щипок |
| **Ключ** | боковий хват: картка, ключ, застібка | пальці стоять «полицею», працює тільки великий |
| **Гак** | нести сумку, пакет | великий палець лишається відкритим, щоб ручка не вискакувала |
| **Вказівка** | кнопка ліфта, тачскрін, вимикач | вказівний завжди прямий |

Жести перемикаються по колу — і подвійним скороченням м'яза, і джойстиком.
Останній обраний жест запам'ятовується.

## Що показує головний екран

```
┌──────────────────────────────────┐
│ Кулак                   ▮▮▯ 78   │  назва жесту  ·  заряд, %
│ ████████████░░░░░░░░░░░░░░░░░░░  │  рівень EMG, засічка — порог
│ ▐▌ ▐▌ ▐▌ ▐▌ ▐▌      Хват   62%    │  стовпчик на кожен палець
│ ██ ██ ██ █░ █░      ┌──────┐     │  (заповнений = зігнутий)
│ ██ ██ ██ ██ ██      │ ФІКС │     │  фіксація хвату
│ ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔  │
│ EMG пропорційний                 │  статус
└──────────────────────────────────┘
```

Засічка на смузі EMG — це порог спрацювання: видно, скільки лишилось
напружитись, щоб кисть почала рухатись.

Замість заряду напис `USB` означає, що батареї немає і плата живиться від
комп'ютера. Замість `ФІКС` напис `спокій` означає, що серво знеструмлені —
кисть розкрита і не витрачає заряд.

### Рядок статусу

| Напис | Що сталось | Що робити |
|---|---|---|
| `EMG пропорційний` / `EMG тригер` / `Ручний режим` | нормальна робота | — |
| `Хват зафіксовано` | хват тримається сам | одне коротке скорочення або клік, щоб зняти |
| `Низький заряд` | нижче 6.8 В | заряджати найближчим часом, рух ще працює |
| **`СТОП: заряд сів`** (інверсією) | нижче 6.2 В, рух заблокований | кисть стоїть де є; розкрити можна джойстиком `↓`; заряджати |
| **`Немає EMG: джойстик`** (інверсією) | електрод відклеївся або сигнал у насиченні | керування вже перейшло на джойстик; поправити електроди |
| **`Потрібне калібрування`** (інверсією) | профіль без валідного калібрування | меню → `Калібрувати EMG` |

Проблемні статуси малюються інверсією — їх видно краєм ока, не вчитуючись.

## Типові ситуації

**Кисть стискається сама, хоча м'яз розслаблений.**
Порог спрацювання нижчий за реальний рівень шуму. Перекалібруйте EMG (могли
зсунутись електроди) або підніміть `Порог увімк.`.

**Треба напружуватись з усіх сил, щоб кисть зрушила.**
Максимум калібрувався, коли м'яз був свіжий, а зараз втомлений. Перекалібруйте
або підніміть `Чутливість`.

**Кисть «дрижить», не доходячи до стиску.**
Замалий зазор між порогами. Зменшіть `Порог вимк.`.

**Жест перемикається сам під час звичайного хвату.**
Скорочення виходять коротшими за 400 мс — стиск робиться різким ривком.
Спробуйте стискати плавніше; якщо не помагає, підніміть `Порог увімк.`.

**Протез перезавантажується під час руху.**
Просадка живлення. Перевірте: конденсатор 1000 мкФ на шині серво, запас по
струму BEC, спільна земля зведена в одну точку. Як тимчасовий обхід —
зменшіть `Швидкість`.

**Кисть повільно повзе сама в ручному режимі.**
Нейтраль джойстика зафіксувалась зі зсувом. Вимкніть і ввімкніть протез, не
торкаючись джойстика.
