# Апаратна архітектура

Повна електрична схема одним аркушем: **[schematic.svg](schematic.svg)**.
Цей документ пояснює рішення, закладені в неї, і фіксує розпіновку. **Прошивка спирається саме на цю
таблицю** — при зміні пінів правити `firmware/ProsthesisArm/Config.h` разом із цим файлом.

## 1. Блок-схема

```
        ┌──────────────┐   envelope 0..Vcc   ┌───────────────┐
  м'яз ─┤ EMG-електроди├────────────────────►│ A0            │
        │ + MyoWare    │                     │               │   PWM ×5   ┌─────────┐
        └──────────────┘                     │  Arduino Nano ├───────────►│ 5× серво│
        ┌──────────────┐   VRx/VRy/SW        │  ATmega328P   │            └─────────┘
        │  джойстик    ├────────────────────►│ A1 A2 D2      │                 ▲
        └──────────────┘                     │               │            6 В  │
        ┌──────────────┐   I2C               │ A4/A5         │         ┌────────┴───────┐
        │ OLED SSD1306 │◄───────────────────►│               │         │ BEC 6 В / 5 А  │
        └──────────────┘                     │ A3 ◄──────────┼──дільник└────────▲───────┘
                                             └───────┬───────┘   напруги        │
                                                     │ 5 В                      │
                                          ┌──────────┴──────────┐               │
                                          │ LDO/step-down 5 В   │               │
                                          └──────────▲──────────┘               │
                                                     │          7.4 В           │
                                             ┌───────┴──────────────────────────┴──┐
                                             │ 2S Li-ion 7.4 В (2×18650) + BMS     │
                                             └─────────────────────────────────────┘
```

Логіка й силова частина живляться від **однієї батареї, але різними
перетворювачами**: просадка від пускового струму серво не має ресетити контролер.
Земля спільна (одна точка з'єднання, «звездою» біля BEC).

## 2. Розпіновка Arduino Nano

| Пін | Напрямок | Призначення | Примітка |
|---|---|---|---|
| D2  | вхід  | Кнопка джойстика (SW) | `INPUT_PULLUP`, є INT0 |
| D3  | вихід | Серво №1 — великий палець | |
| D4  | вихід | Серво №2 — вказівний | |
| D5  | вихід | Серво №3 — середній | |
| D6  | вихід | Серво №4 — безіменний | |
| D7  | вихід | Серво №5 — мізинець | |
| D8  | вихід | Зумер/вібромотор (тактильний фідбек) | опційно |
| D9  | —     | **резерв**: серво зап'ястка | |
| D10–D13 | — | резерв (D11–D13 = SPI) | |
| A0  | вхід (ADC) | **EMG канал 1** — envelope-вихід | згинач кисті |
| A1  | вхід (ADC) | Джойстик VRx | |
| A2  | вхід (ADC) | Джойстик VRy | |
| A3  | вхід (ADC) | Напруга батареї через дільник | |
| A4  | I2C | SDA — OLED | |
| A5  | I2C | SCL — OLED | |
| A6  | вхід (ADC) | **резерв**: EMG канал 2 (розгинач) | тільки аналоговий вхід |
| A7  | вхід (ADC) | резерв | тільки аналоговий вхід |

`Servo.h` на ATmega328P використовує Timer1 і генерує імпульси програмно, тому серво
можуть сидіти на **будь-яких** цифрових пінах — саме тому вибрані підряд D3…D7
(зручна розводка шлейфа). Побічний ефект: апаратний PWM на D9/D10 недоступний.

## 3. Дільник напруги батареї (A3)

```
Vbat(+) ──[ R1 = 100 кОм ]──┬── A3
                            │
                    [ R2 = 47 кОм ]   [ C = 100 нФ ]
                            │              │
GND ────────────────────────┴──────────────┴──
```

* Коефіцієнт дільника: `(100 + 47) / 47 = 3.128`
* При максимумі 8.4 В на A3 буде `8.4 / 3.128 = 2.69 В` — з великим запасом до 5 В.
* Конденсатор 100 нФ гасить пульсації від серво, щоб індикатор заряду не «стрибав».
* Струм через дільник ~57 мкА — допустимий саморозряд для 18650.

Робочий діапазон 2S Li-ion: **8.4 В (100 %) … 6.4 В (0 %)**. Нижче 6.0 В
прошивка блокує рух серво, щоб BMS не відрубив живлення посеред стиску.

## 4. Бюджет струму

| Споживач | Типово | Пік |
|---|---|---|
| 5 × MG90S (рух) | ~150 мА кожне | ~700 мА кожне (стоп-момент) |
| Arduino Nano | 20 мА | 40 мА |
| OLED SSD1306 | 8 мА | 20 мА |
| EMG-модуль | 9 мА | 14 мА |
| **Разом** | **~0.8 А** | **~3.6 А** |

Вимоги до BEC на шину серво: **6 В, тримає 5 А** (запас ×1.4 до піку).
Обов'язково електролітичний конденсатор **1000 мкФ / 10 В** на шині серво поруч
з роз'ємами — він гасить пускові кидки струму.

Прошивка додатково обмежує пік програмно: серво рухаються з обмеженням швидкості
(slew rate) і не всі одночасно на максимальній швидкості — див. модуль `Hand`.

## 5. EMG-тракт

Використовується модуль з **готовим envelope-виходом** (MyoWare 2.0 «ENV» або
аналог): всередині вже є інструментальний підсилювач, смуговий фільтр 20–500 Гц,
двопівперіодний випрямляч і згладжування. На виході — повільна огинаюча 0…Vcc,
пропорційна силі скорочення м'яза. Тому Arduino не займається цифровою фільтрацією
сирого сигналу — лише усередненням, калібруванням і порогами.

Розміщення трьох електродів (для згинача кисті, m. flexor carpi radialis):

* **+** і **−** — по ходу м'язового волокна, на відстані 2–3 см один від одного,
  на найтовщій частині м'яза;
* **REF** (референс) — на електрично «тихому» місці: кістковий виступ ліктя
  (olecranon) або зовнішня сторона передпліччя.

Шкіру протерти спиртом і дати висохнути; для багаторазових електродів —
провідний гель. Кабель до модуля тримати коротким і не паралельно силовим
проводам серво.
