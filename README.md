# Adaptive Prosthetic Arm (below-elbow) — ProsthesisArm

Відкритий проєкт адаптивного протеза кисті для людей, які втратили кінцівку **нижче
локтя** (transradial amputation). Керування — міоелектричне (EMG-електроди на
передпліччі) з дублюючим ручним інтерфейсом: джойстик + OLED-екран.

> **Статус:** активна розробка. Це дослідницький/навчальний проєкт.
> Це **не** сертифікований медичний виріб — див. [Безпека та обмеження](#безпека-та-обмеження).

---

## Ідея

Людина з ампутацією нижче локтя зберігає м'язи передпліччя. Коли вона намагається
стиснути «фантомну» кисть, м'язи-згиначі все одно скорочуються, і на шкірі виникає
електричний потенціал — його і читають EMG-електроди. Система перетворює силу
скорочення у стиск протеза, а джойстик з екраном дозволяють обрати **жест**
(кулак, щипок, вказівний палець, «ключ», відкрита долоня тощо) і відкалібрувати
систему під конкретного користувача.

Ключове слово — **адаптивний**:

* калібрування під м'язи конкретної людини (рівень спокою + максимальне скорочення),
* пропорційне керування: слабке скорочення — слабкий/повільний стиск, сильне — повний,
* збереження профілю в EEPROM, щоб протез «пам'ятав» користувача після вимкнення,
* повний ручний резерв, якщо EMG-сигнал поганий (спітніла шкіра, зсув електродів).

## Апаратна база

| Вузол | Компонент | Примітка |
|---|---|---|
| Контролер | Arduino Nano (ATmega328P, 5 В) | 2 КБ RAM, 32 КБ Flash |
| Приводи | 5 × серво (по одному на палець) | MG90S / MG996R залежно від сили хвату |
| Датчик | 1 × EMG-модуль з envelope-виходом | MyoWare 2.0 або аналог |
| Екран | OLED 128×64 SSD1306, I2C | бібліотека U8g2 |
| Ввід | 2-осьовий джойстик з кнопкою | аналоговий, KY-023 |
| Живлення | 2S Li-ion 7.4 В + BMS | 2 × 18650 |
| Стабілізація | BEC/step-down 6 В (серво) + 5 В (логіка) | окремі шини, спільна земля |

### Модулі прошивки

| Файл | За що відповідає |
|---|---|
| `ProsthesisArm.ino` | кооперативний цикл без `delay()`, розподіл подій |
| `Config.h` | вся розпіновка та фізичні константи — єдине джерело правди |
| `Profile.*` | персональний профіль користувача, EEPROM, CRC16 |
| `Emg.*` | нормування сигналу, розпізнавання намірів, контроль якості |
| `Gestures.*` | бібліотека жестів у PROGMEM, пропорційна інтерполяція |
| `Hand.*` | 5 серво: обмеження швидкості, ліміт пускового струму |
| `Joystick.*` | дискретні події з автоповтором + пропорційні осі |
| `Battery.*` | 2S Li-ion: справжній Vcc через bandgap, крива розряду |
| `Controller.*` | намір користувача → положення кисті, безпека, фіксація хвату |
| `Ui.*` | OLED: головний екран, меню, майстри калібрування |

## Швидкий старт

Потрібні бібліотеки: **Servo** і **EEPROM** (входять у ядро `arduino:avr`),
**U8g2** (olikraus).

```bash
arduino-cli core install arduino:avr
arduino-cli lib install "U8g2"
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328 firmware/ProsthesisArm
arduino-cli upload  --fqbn arduino:avr:nano:cpu=atmega328 -p COM3 firmware/ProsthesisArm
```

Далі: [підключення](docs/wiring.md) → [калібрування](docs/calibration.md) →
[керування](docs/usage.md).

Для налагодження EMG розкомментуйте `PROSTHESIS_DEBUG_SERIAL` у `Config.h` —
прошивка почне віддавати телеметрію у форматі Serial Plotter (сирий сигнал,
активація, хват, напруга).

## Безпека та обмеження

* Проєкт не проходив клінічних випробувань і не є медичним виробом.
* Li-ion збірка **обов'язково** з BMS та захистом від перезаряду/КЗ.
* Серводвигуни мають обмеження по струму та програмний ліміт кута, щоб не травмувати
  користувача і не зламати механіку.
* Електроди — тільки пасивні поверхневі, гальванічно не зв'язані з мережею 230 В.
  Прошивку заливати від ноутбука **на батареї** або через USB-ізолятор.
* Прошивка **ще не запускалась на живому обладнанні**: код написаний, але не
  скомпільований і не перевірений на залізі. До першого запуску ставитись як
  до чернетки, а не як до робочої версії.
